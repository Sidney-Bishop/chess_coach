# chess_coach Knowledge Bundle

This is the **entry point**. Read this file first, pick the one or two concepts
whose descriptions match what you need, and read only those. Descriptions below
say what each concept is *for* — they deliberately do not summarise its contents,
because a summary here would rot.

* [Overview](/overview.md) - Orientation for chess_coach — what it is, what it is deliberately not, the current state, and where to read next.
* [Conventions](/conventions.md) - How this bundle is produced (type vocabulary, `<ID>-<slug>` filenames with slug-freeze, supersession and closure shapes, the as-of-date rule) and how work is done here.
* [Architecture](/architecture.md) - How chess_coach is built right now — components, data flow, external services, and the non-obvious constraints.
* [Pitfalls & invariants](/pitfalls.md) - Load-bearing constraints that fail quietly when broken by accident.
